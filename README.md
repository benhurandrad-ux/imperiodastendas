# Site Império das Tendas

Site estático (HTML único + assets + GSAP local). Publicado via GitHub Pages em https://imperiodastendas.benhurandrade.com.br

- `index.html` fonte do site
- `assets/` fotos otimizadas e camadas da logo
- `vendor/` GSAP e ScrollTrigger
- `build_artifact.py` gera `../artifact.html` (versão com tudo embutido, para preview no Claude)
